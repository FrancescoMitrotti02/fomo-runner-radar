# FOMO Runner Radar — Web / iPhone Edition

Versione web del radar FOMO, ottimizzata per uso da Safari su iPhone.

## Funzioni
- FOMO Trending
- Most-held
- Graduated
- Thesis feed
- Early Runner Score
- Performance dopo 1h / 2h / 4h / 6h / 12h / 24h / 48h / 72h / 7 giorni
- Storico token
- Dashboard mobile responsive
- Deploy tramite Docker / Render / Railway

## Avvio locale
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy web
Leggi `DEPLOY_IPHONE.md`.

## iPhone
Dopo il deploy, apri l'URL in Safari e usa:
**Condividi → Aggiungi alla schermata Home**.

In questo modo appare come un'icona sulla Home e si apre come una web app.
